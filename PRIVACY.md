# Privacy Policy for DSA Problem Downloader

**Last updated:** 2026-05-30

## What Data We Collect

DSA Problem Downloader does **not** collect, store, or transmit any personal data or browsing information.

## How the Extension Works

When you click the extension icon on a supported problem page (LeetCode or GeeksforGeeks), the extension reads the problem title, description, and starter code from the page's existing structured data. This data is used solely to generate a downloadable file on your device. No data leaves your browser.

## Third-Party Services

This extension does not use any third-party services, analytics, cookies, or tracking mechanisms.

## Data Storage

The extension does not use `chrome.storage`, local storage, or any other persistence mechanism. Each interaction is independent — no history of downloaded problems is kept.

## Data Sharing

No data is shared with any third party. Ever.

## Changes to This Policy

If this privacy policy changes, updates will be posted to this page. The "Last updated" date at the top will be revised accordingly.
